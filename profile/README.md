# Satisium

**Everything is Code. Context is Premium.**

Satisium is a suite of code-native design engineering tools built for React, Next.js, and Tailwind CSS. No proprietary design files, no lock-in—just raw, copy-owned, AI-legible code.

### Tools

| Tool | Description | Status |
| :--- | :--- | :--- |
| **[Ease](https://ease.satisium.com)** | Local-first kinetic curve workbench for previewing, comparing, and exporting Bézier & Spring physics. | Live (`v1.0`) |
| **[Satisium UI](https://ui.satisium.com)** | Open-code, `shadcn`-compatible animated React primitives and blocks. | Live |
| **[Tweak](https://tweak.satisium.com)** | In-app visual workbench for live prop editing, Git-like UI branching, and clean AST write-back. | Building |
