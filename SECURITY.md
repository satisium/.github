# Security Policy

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, report vulnerabilities confidentially using **GitHub Private Vulnerability Reporting** (`Security` tab → `Advisories` → `Report a vulnerability` on the affected repository).

Please include:
- A clear description of the issue and affected component or route.
- Minimal steps or a proof of concept to reproduce.
- Any potential impact or suggested remediation.

We will acknowledge receipt and work toward a fix and coordinated disclosure as quickly as possible.
